esp32-hud-system
基于 ESP32 实现的车载 HUD 显示系统，使用 FreeRTOS 多任务调度，搭配 OLED 显示屏与姿态传感器，实现实时数据可视化。
功能简介
·OLED 显示屏驱动（SSD1306 I2C 接口）
·LVGL 图形库界面绘制与动画效果
·IMU 姿态数据实时解析
·RMT 驱动 RGB 氛围灯
·多任务架构：显示任务、传感器采集、灯光控制分离
硬件连接（I2C OLED）
      ESP Board         OLED LCD (I2C)
+------------------+    +-------------------+
|               GND+----+GND                |
|               3V3+----+VCC                |
|               SDA+----+SDA                |
|               SCL+----+SCL                |
+------------------+    +-------------------+
开发环境
·ESP-IDF 5.x
·LVGL 图形库
·支持芯片：ESP32 / ESP32-S3
编译与烧录
idf.py build flash monitor
代码说明
本项目基于乐鑫官方 I2C OLED 例程二次开发，在原有驱动基础上重构任务架构、扩展传感器数据解析与 HUD 界面逻辑，仅用于学习与求职展示，非商用。
